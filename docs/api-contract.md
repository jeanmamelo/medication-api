# HTTP API contract

Base path: `/v1`

## Medication resource

```json
{
  "id": "018f2f15-0cf5-7e54-9ecb-65df2a99e422",
  "name": "Paracetamol",
  "dosage": "500 mg",
  "form": "tablet"
}
```

`id` is generated by the server. `name`, `dosage`, and `form` are required, trimmed strings.

## Operations

| Method | Path | Description | Success |
| --- | --- | --- | --- |
| `POST` | `/v1/medications` | Create a medication. | `201 Created` |
| `GET` | `/v1/medications` | List medications with bounded pagination. | `200 OK` |
| `GET` | `/v1/medications/{id}` | Retrieve one medication. | `200 OK` |
| `PATCH` | `/v1/medications/{id}` | Partially update one medication. | `200 OK` |
| `DELETE` | `/v1/medications/{id}` | Delete one medication. | `204 No Content` |

## Error shape

```json
{
  "error": {
    "code": "validation_failed",
    "message": "request validation failed"
  }
}
```

The public message is stable and safe to expose.
